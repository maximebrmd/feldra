## SaaS ऐप्स परिनियोजित करें [#deploy-the-saas-apps]

अपने Next.js होस्ट पर दो प्रोजेक्ट बनाएँ और उन्हें उसी जनरेट की गई रिपॉज़िटरी से जोड़ें:

| प्रोजेक्ट | रूट डायरेक्टरी | उद्देश्य |
| --- | --- | --- |
| मार्केटिंग | `apps/web` | लैंडिंग पेज और मूल्य निर्धारण |
| एप्लिकेशन | `apps/app` | प्रमाणीकरण, डैशबोर्ड, API, वेबहुक |

रूट npm लॉकफ़ाइल के अनुसार सभी वर्कस्पेस सहित निर्भरताएँ इंस्टॉल करें। प्रत्येक प्रोजेक्ट की रूट डायरेक्टरी के बाहर की स्रोत फ़ाइलों तक पहुँच सक्षम करें, ताकि Next.js साझा पैकेजों को संकलित कर सके। प्लेटफ़ॉर्म के Next.js प्रीसेट का उपयोग करें।

## प्रोडक्शन ओरिजिन सेट करें [#set-production-origins]

दोनों परिनियोजनों पर `WEB_URL` और `APP_URL` को उनके सटीक HTTPS ओरिजिन पर सेट करें। डेटाबेस, प्रमाणीकरण, Stripe और Resend के क्रेडेंशियल केवल एप्लिकेशन परिनियोजन पर सेट करें।

प्रोडक्शन के लिए एक नया प्रमाणीकरण सीक्रेट, प्रोडक्शन डेटाबेस, सत्यापित प्रेषक और परस्पर मेल खाने वाले Stripe लाइव कुंजी, मूल्य, एंडपॉइंट सीक्रेट तथा मोड का उपयोग करें। प्रमाणीकरण कुकीज़ एप्लिकेशन ओरिजिन से संबंधित होती हैं।

## माइग्रेशन लागू करें [#apply-migrations]

एप्लिकेशन का ट्रैफ़िक इच्छित डेटाबेस की ओर भेजने से पहले उस डेटाबेस पर `npm run db:migrate` चलाएँ। प्रत्येक माइग्रेशन की समीक्षा करें और ऐसे बदलावों से पहले महत्वपूर्ण डेटा का बैकअप लें, जो उसे हटा सकते हैं या रूपांतरित कर सकते हैं।

## लॉन्च से पहले सत्यापित करें [#verify-before-launch]

वास्तविक होस्ट किए गए एप्लिकेशन पर सत्यापन लिंक, पासवर्ड रीसेट, सत्र निरस्तीकरण, निजी रिकॉर्ड तक पहुँच का प्राधिकरण, Checkout, पोर्टल में बदलाव और वेबहुक डिलीवरी का परीक्षण करें। टेम्पलेट के स्थानीय परीक्षण फ़िक्स्चर आपके प्रोडक्शन कॉन्फ़िगरेशन को सत्यापित नहीं करते हैं।

## यह दस्तावेज़ीकरण साइट [#this-documentation-site]

Feldra का दस्तावेज़ीकरण एक अलग स्थिर Astro ऐप है। टेम्पलेट रिपॉज़िटरी की रूट डायरेक्टरी से चलाएँ:

```sh
npm run build --workspace docs
npm run preview --workspace docs
```

आउटपुट `apps/docs/dist` है। इसे डायरेक्टरी-इंडेक्स रूटिंग और जनरेट की गई `404.html` के साथ किसी स्थिर होस्ट से उपलब्ध कराया जा सकता है। किसी सर्वर अडैप्टर या प्रदाता के क्रेडेंशियल की आवश्यकता नहीं है। दस्तावेज़ीकरण ऐप को जनरेट किए गए SaaS प्रोजेक्ट में शामिल नहीं किया जाता है। कुछ भी स्वचालित रूप से परिनियोजित नहीं होता है।
