## रिलीज़ की स्थिति [#release-status]

Feldra इस परियोजना का नया ब्रांड है। इनिशियलाइज़र का वर्तमान नाम `create-feldra` है और इसे अभी npm पर प्रकाशित नहीं किया गया है। अनुरक्षक Changesets के माध्यम से संस्करणों का प्रबंधन करते हैं।

## रिलीज़ की कार्यप्रक्रिया [#release-workflow]

```sh
npm run changeset
npm run changeset:status
npm run release:version
```

संस्करण कमांड लंबित टिप्पणियों को संसाधित करता है, `initializer/CHANGELOG.md` बनाता है, इनिशियलाइज़र और रूट के संस्करणों को अपडेट करता है, और लॉकफ़ाइल को अद्यतन करता है। यह प्रकाशित नहीं करता है। स्पष्ट रूप से अधिकृत npm प्रकाशन से पहले पैक किए गए आर्टिफ़ैक्ट का परीक्षण करें।

## स्थानीय रिलीज़ का इतिहास [#local-release-history]


### 0.3.0

- तीर कुंजियों से इंटरैक्टिव Neon/Supabase डेटाबेस चयन, साथ ही CI के लिए `--database`।
- प्रदाता के अनुसार जनरेट किए गए सेटअप निर्देश, परिवेश संबंधी टिप्पणियाँ और स्रोत का मेटाडेटा।
- सभी निजी तालिकाओं पर RLS सक्षम करें; सर्वर पर स्वामित्व की जाँच और साझा Postgres/Drizzle पहुँच बनाए रखें।
- पैक की गई npm रिलीज़ से दोनों डेटाबेस विकल्पों का परीक्षण करें।


### 0.2.0 — अप्रकाशित [#020-\-unreleased]

- अलग-अलग मार्केटिंग और प्रमाणीकरण वाले Next ऐप्स, स्रोत कोड निर्यात करने वाले छह साझा पैकेजों और Turborepo के साथ next-forge शैली का npm मोनोरेपो जनरेट करें।
- टर्मिनल में सेटअप/समीक्षा प्रॉम्प्ट और `--preset neon` जोड़ें, तथा `--yes`/गैर-TTY स्वचालन बनाए रखें। ऐसे प्रदाताओं के विकल्प शामिल न करें जिन्हें लागू नहीं किया गया है।
- लागू किए गए Neon/Better Auth/Stripe/Resend टूलकिट और अपरिवर्तित डेटाबेस माइग्रेशन को बनाए रखें।
- दोनों प्रोडक्शन ऐप्स, ऐप्स के बीच नेविगेशन, वर्कस्पेस टास्क ग्राफ़ और वास्तविक पैक किए गए वितरण का परीक्षण करें। पहले से जनरेट की गई परियोजनाएँ अपने-आप संशोधित नहीं होती हैं।

### 0.1.0 — अप्रकाशित [#010-\-unreleased]

प्रारंभिक एकल-ऐप SaaS आधार और साथ में शामिल npm इनिशियलाइज़र। 0.2.0 में अनुरोधित मोनोरेपो आर्किटेक्चर ने इसका स्थान ले लिया।
