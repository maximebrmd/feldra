## गुणवत्ता जाँच [#quality-checks]

```sh
npm run check
```

दोनों ऐप के लिए Ultracite लिंटिंग, TypeScript जाँच, नीति/इनपुट परीक्षण और प्रोडक्शन बिल्ड चलाता है। बिल्ड के लिए लाइव प्रदाता क्रेडेंशियल की आवश्यकता नहीं है।

## डेटाबेस फ़िक्स्चर [#database-fixtures]

```sh
npm run test:database
```

Docker एक पृथक स्थानीय Postgres डेटाबेस शुरू करता है, माइग्रेशन चलाता है और वास्तविक Better Auth सत्रों, रिकॉर्ड के स्वामित्व, अमान्य इनपुट, RLS, हस्ताक्षरित वेबहुक, डुप्लिकेट डिलीवरी, पुनः प्रयास के रोलबैक और सदस्यता के आधार पर पहुँच का परीक्षण करता है। Stripe और Resend की नेटवर्क कॉल को फ़िक्स्चर से बदल दिया जाता है।

## ब्राउज़र कार्यप्रवाह [#browser-flows]

```sh
npm run test:browser
```

दोनों ऐप के बिल्ड बनाता है, स्थानीय प्रोडक्शन सर्वर और एक अस्थायी डेटाबेस शुरू करता है तथा मार्केटिंग नेविगेशन, लॉगिन, ऑनबोर्डिंग, नोट्स, सेटिंग्स, मोबाइल लेआउट, लॉगआउट और रूट सुरक्षा का परीक्षण करता है।

## प्रदाता सत्यापन [#provider-verification]

स्थानीय फ़िक्स्चर से लाइव Neon या Supabase कनेक्टिविटी, Resend डिलीवरी, Stripe Checkout या प्रोडक्शन होस्टिंग की पुष्टि नहीं होती। लॉन्च से पहले अलग परीक्षण संसाधनों के साथ ये जाँच चलाएँ।
