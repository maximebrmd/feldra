Feldra, SaaS के आवश्यक हिस्सों को आपके स्वामित्व वाले कार्यक्षेत्र में एक साथ लाता है। मार्केटिंग, प्रमाणीकरण, निजी डेटा, सदस्यताएँ और लेन-देन संबंधी ईमेल आपस में जुड़े होते हैं, ताकि आप अपने उत्पाद पर ध्यान केंद्रित कर सकें।

## एक आधार, कोई प्लेटफ़ॉर्म नहीं [#a-foundation-not-a-platform]

आपकी जनरेट की गई परियोजना एक स्वतंत्र Git रिपॉज़िटरी होती है, जिसकी अपनी निर्भरताएँ, डेटाबेस और प्रदाता क्रेडेंशियल होते हैं। रनटाइम पर यह इस टेम्पलेट या इसके इनिशियलाइज़र पर निर्भर नहीं होती है।

इसकी आर्किटेक्चर next-forge से प्रेरित है: दो डिप्लॉय किए जा सकने वाले Next.js ऐप और साझा पैकेजों का एक छोटा समूह, जिन्हें Turborepo और npm workspaces के माध्यम से समन्वित किया जाता है।

## आपको क्या मिलता है [#what-you-get]

- **एक सार्वजनिक वेबसाइट**, जिसमें लैंडिंग और मूल्य निर्धारण के पेज होते हैं।
- **एक प्रमाणीकरण युक्त ऐप**, जिसमें साइनअप, सत्यापन, लॉगिन, पासवर्ड रीसेट, ऑनबोर्डिंग और खाता सेटिंग्स होती हैं।
- **निजी नोट्स**, जो सत्यापन और प्राधिकरण जाँच वाले CRUD के स्पष्ट रूप से चिह्नित उदाहरण हैं।
- **सदस्यताएँ**, जिनमें Stripe Checkout, ग्राहक पोर्टल, हस्ताक्षरित वेबहुक और सर्वर की ओर से नियंत्रित सशुल्क पहुँच शामिल हैं।
- Resend के माध्यम से **लेन-देन संबंधी ईमेल**।
- **एक परीक्षित कार्यप्रवाह**, जिसमें Ultracite, TypeScript, प्रोडक्शन बिल्ड, डेटाबेस फ़िक्स्चर और ब्राउज़र जाँच शामिल हैं।

## एक छोटा, सोच-समझकर चुना गया स्टैक [#a-small-deliberate-stack]

| कार्यक्षेत्र | शामिल टूल |
| --- | --- |
| एप्लिकेशन | Next.js App Router और TypeScript |
| डेटाबेस | Drizzle के साथ Neon या Supabase Postgres |
| प्रमाणीकरण | Better Auth |
| स्टाइलिंग | Tailwind CSS और उपयोग किए गए shadcn/ui कॉम्पोनेंट |
| बिलिंग | Stripe |
| ईमेल | Resend |
| गुणवत्ता | Ultracite, TypeScript और परीक्षण |

व्यक्तिगत खाते और उपयोगकर्ता-स्तरीय बिलिंग इसका मूल आधार हैं। संगठन, AI, क्यू, CMS, एनालिटिक्स और रीयलटाइम सहयोग को जानबूझकर इसके दायरे से बाहर रखा गया है।

## निर्माण शुरू करें [#start-building]

अपनी पहली स्वतंत्र परियोजना बनाने के लिए [त्वरित शुरुआत](/docs/quickstart/) पर जाएँ, या शुरू करने से पहले [आर्किटेक्चर](/docs/architecture/) के बारे में जानें।

> Feldra इस परियोजना का नया नाम है। GitHub रिपॉज़िटरी `maximebrmd/feldra` है। इनिशियलाइज़र `create-feldra` है। इसका सार्वजनिक npm कमांड प्रकाशन के बाद उपलब्ध होगा।
