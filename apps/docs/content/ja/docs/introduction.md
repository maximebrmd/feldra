Feldraは、SaaSに欠かせない要素を、自分で所有するワークスペースにまとめます。マーケティング、認証、プライベートデータ、サブスクリプション、トランザクションメールが連携しているため、プロダクトに集中できます。

## プラットフォームではなく、基盤です [#a-foundation-not-a-platform]

生成されるプロジェクトは、独自の依存関係、データベース、プロバイダーの認証情報を持つ、独立したGitリポジトリです。実行時にこのテンプレートや初期化ツールに依存することはありません。

アーキテクチャはnext-forgeから着想を得ています。デプロイ可能な2つのNext.jsアプリと少数の共有パッケージを、Turborepoとnpm workspacesで連携させます。

## 含まれる機能 [#what-you-get]

- **公開ウェブサイト**には、ランディングページと料金ページが含まれます。
- **認証機能付きアプリ**には、新規登録、検証、ログイン、パスワードリセット、オンボーディング、アカウント設定が含まれます。
- **プライベートノート**は、入力検証と認可を備えたCRUDのサンプルとして、明確に示されています。
- **サブスクリプション**には、Stripe Checkout、カスタマーポータル、署名付きWebhook、サーバー側での有料アクセス制御が含まれます。
- **トランザクションメール**はResend経由で送信します。
- **テスト済みのワークフロー**には、Ultracite、TypeScript、本番ビルド、データベースフィクスチャ、ブラウザーでの検証が含まれます。

## 厳選した最小限の技術スタック [#a-small-deliberate-stack]

| 用途 | 含まれるツール |
| --- | --- |
| アプリケーション | Next.js App RouterとTypeScript |
| データベース | NeonまたはSupabase PostgresとDrizzle |
| 認証 | Better Auth |
| スタイリング | Tailwind CSSと使用するshadcn/uiコンポーネント |
| 課金 | Stripe |
| メール | Resend |
| 品質 | Ultracite、TypeScript、テスト |

個人アカウントとユーザー単位の課金を基本としています。組織、AI、キュー、CMS、アナリティクス、リアルタイムの共同作業は、意図的に対象外としています。

[クイックスタート](/docs/quickstart/)に進んで最初の独立したプロジェクトを作成するか、始める前に[アーキテクチャ](/docs/architecture/)を確認してください。
