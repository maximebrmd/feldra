# Documentation

This generated project includes a Blume documentation app. From the repository root:

```sh
npm run docs:dev
npm run docs:build
```

Open http://localhost:4321. Edit Markdown in `apps/docs/content/docs`. The Feldra monorepo's own product docs stay on Blume in that repository; this app documents the generated SaaS.

Guides here cover introduction, provider setup, and architecture. Additional operator notes remain in the repository `docs/` directory.
